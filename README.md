1. The part that gave me the most trouble was understanding how an NFA can have multiple possible paths at the same time. I had to get used to checking all possible next states instead of only following one path. I did not avoid any problems because they were too challenging. I wanted to use the assignment to get more practice with NFAs and JFLAP. I did ask AI questions when I was confused about JFLAP's state transitions and how to check my computation trees. I used it mainly to understand my mistakes and check my work.
2. The "gold-st-rings" helped me notice how easy it is to miss a possible state when an NFA has multiple paths. Drawing the computation tree by hand and then comparing it with JFLAP helped me understand this better. In the future, I can avoid these mistakes by writing down all the possible states after reading each input symbol instead of following only one path.
3. One thing I learned is that an NFA only needs one path to reach an accepting state for the string to be accepted. Other paths can end in non-accepting states and the string can still be accepted. I also got more comfortable using JFLAP to test my NFAs and understand how the different state transitions work.
